# تطبيق تصميم القالب على كل أنواع الصفحات — محتوى ووردبريس الديناميكي

التصميم البصري مأخوذ من ملفات HTML المرفقة (19 نوع صفحة، نفس نظام الألوان والهيدر/الفوتر). **المحتوى ليس ثابتاً**: العناوين، النصوص، التصنيفات، المدن، الأسئلة، النماذج، الهاتف وواتساب تُقرأ من ووردبريس (المقالات، الصفحات، التصنيفات، ThemeOptions، الويدجت).

## أين يعيش القالب

- مصدر القالب: `kayan-theme/` في هذا المستودع (نسخة من KAYAN جاهزة للرفع).
- نفس التعديلات على مستودع القالب `m-elsaad22/Kayan-Theme` (فرع `cursor/apply-kit-theme-db2a`).
- أرشيف الرفع: `dist/kayan-theme-2027.zip` — يُرفع من المظهر → قوالب → أضف جديد.

الإصدار: **1.5.0** (أصول CSS/JS `1.5.0`).

## ما الذي تغيّر

| نوع الصفحة في القالب | قالب ووردبريس | مصدر المحتوى |
|---|---|---|
| الرئيسية | `kayan-homepage` v3 | ThemeOptions + توكنات `{{…}}` |
| الخدمات / التصنيفات | نموذج الصفحة `categories` | تصنيف `category` |
| خدمة مفردة | `@single/post.php` | عنوان/محتوى المقال + ويدجت الشريط |
| أرشيف تصنيف | `@archive/default.php` | التصنيف + المقالات |
| المدن | نموذج `cities` | تصنيف `city` |
| مدينة مفردة | `@archive/city.php` | وصف المدينة + الخدمات |
| من نحن / سياسة / شروط | `standard-page` | محتوى الصفحة |
| المدونة | نموذج `blog` | مقالات `post` |
| تواصل | نموذج `contact-us` | خيارات التواصل + ويدجت النموذج |
| أسئلة | نموذج `faqs` | نوع محتوى `faq` |
| العروض / الأسعار | نموذج `price` | محتوى الصفحة + ويدجت |
| المشاريع | نموذج `works` | نوع محتوى `works` |
| بحث / كاتب | `@search` / `@author` | استعلام ووردبريس |
| 404 | `@404` | روابط الصفحات الحقيقية + واتساب الموقع |

الهيدر/الفوتر/البحث/واتساب مشتركة لكل الصفحات وتُقرأ من الشعار، القائمة الرئيسية، وخيارات التواصل — ليست نصوص القالب التجريبي (دبي / 971586634710).

## التحكم من لوحة ووردبريس

- **الهيدر**: الشعار من إعدادات الهيدر، الروابط من المظهر → القوائم (`main-menu`).
- **الرئيسية**: ThemeOptions → إعدادات الصفحة الرئيسية (البطل، الإحصائيات، إخفاء الأقسام).
- **الصفحات الداخلية**: حرّر عنوان الصفحة ومحتواها كالمعتاد؛ البطل يأخذ العنوان + مقتطف المحتوى أو وصف SEO.
- **الخدمات/المدن**: أضف أو عدّل التصنيفات والمقالات.
- **النماذج**: ويدجت صفحة التواصل كما هي.
- لا يغيّر هذا التحديث عناوين Rank Math التي تحتوي «للإيجار» أو الأرقام المصرية.

## ملاحظات تقنية

- ألوان القالب: `--navy:#0A1F4E` / `--turq:#2E9DF7` / `--gold:#C9A227`.
- CSS القديم (`main.css` / `hover.css` / `responsive.css`) لا يُحمَّل على صفحات التصميم الجديد حتى لا يتعارض مع القالب.
- المحتوى التجريبي داخل ملفات HTML المرفقة **غير منسوخ** إلى القالب.
