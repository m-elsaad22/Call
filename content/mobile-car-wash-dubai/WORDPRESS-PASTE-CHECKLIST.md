## A) Hub جديد — احفظ **Draft** فقط

### A1. إنشاء المقال

1. المقالات → أضف جديداً. النوع: **مقال (`post`)** — ليس خدمة CPT.
2. العنوان (يصير H1 القالب) — الصق حرفياً:

```
غسيل سيارات متنقل في دبي
```

3. الرابط / slug:

```
mobile-car-wash-dubai
```

الرابط النهائي يجب أن يكون فقط:

```
https://www.rukn-eltatawer.com/mobile-car-wash-dubai/
```

لا تستخدم `/services/mobile-car-wash-dubai/`.

### A2. Rank Math — املأ **قبل أول حفظ**

لا تترك SEO Title فارغاً.

| الحقل | القيمة حرفياً |
|---|---|
| SEO Title | `غسيل سيارات متنقل في دبي \| عند المنزل والمكتب \| ركن التطور` |
| Meta Description | `غسيل سيارات متنقل في دبي من 60 درهماً. نصل إلى المنزل أو المكتب أو الموقف. احجز عبر واتساب ركن التطور واختر إحدى الباقات الثلاث.` |
| Focus keyword | `غسيل سيارات متنقل في دبي` |
| Canonical | `https://www.rukn-eltatawer.com/mobile-car-wash-dubai/` |
| Robots | index, follow |

### A3. الجسم

1. المحرر → وضع HTML / Custom HTML.
2. الصق **كامل** `hub/content.html` (بما في ذلك `<style>`).
3. لا تضف `<h1>`.
4. لا تلصق أي `<script type="application/ld+json">`.

### A4. FAQ Schema

الأسئلة ظاهرة في HTML. أنشئ بلوك **Rank Math FAQ** وانسخ نفس الأزواج (لا JSON-LD يدوي):

1. كم سعر غسيل السيارات المتنقل في دبي؟
2. هل تصلون إلى المنزل؟
3. هل تصلون إلى مواقف الأبراج؟
4. هل تقدمون الخدمة في جميع مناطق دبي؟
5. كم يستغرق غسيل السيارة؟
6. هل يمكن غسيل SUV؟
7. هل توفرون تنظيفاً داخلياً؟
8. هل تقدمون غسيلاً بالبخار؟
9. هل يوجد غسيل بدون ماء؟
10. هل أحتاج إلى توفير الماء أو الكهرباء؟
11. هل يمكن حجز موعد؟
12. هل تقدمون اشتراكات شهرية؟
13. هل تخدمون الشركات والأساطيل؟
14. ما الفرق بين هذه الصفحة وصفحة البخار؟
15. هل تغسلون السيارة أثناء تنظيف الكراج؟

النص من `hub/content.html` كما هو (بما فيه TODO الظاهر).

### A5. تصنيف

- تصنيف المقالات: **الخدمات** (`service`)
- تصنيف المدن: **دبي** (`dubai` / term 2874) — هذا فقط. لا تُسند البخار.
- وسوم مقترحة: `غسيل سيارات متنقل`، `سيارات`، `دبي`، `خدمة متنقلة`

`/city/dubai/` يبقى نفس الرابط؛ بعد النشر لاحقاً تظهر بطاقة ثانية.

### A6. صورة

- **لا صورة بارزة.**
- لا رفع مخزن / مولَّد / عشوائي.

### A7. تحقق الأسعار في المعاينة

يجب أن تظهر ثلاث باقات فقط:

| الباقة | الآن | مشطوب |
|---|---|---|
| غسيل عادي | 60 درهماً | 90 درهماً |
| غسيل مع تلميع داخلي وخارجي | 90 درهماً | 120 درهماً |
| غسيل وتلميع احترافي عميق | 349 درهماً | 500 درهماً |

### A8. حفظ

**احفظ مسودة (Draft).** لا تضغط «نشر».
