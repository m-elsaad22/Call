# ديمو أنواع الصفحات

**التصميم المعتمد:** الملفات المرفقة في جذر المشروع (ليست صفحات `demos/`).

من جذر المستودع:

```bash
python3 -m http.server 8765
```

- فهرس الأنواع: http://127.0.0.1:8765/preview.html
- الرئيسية: http://127.0.0.1:8765/index.html

هذا المجلد (`demos/`) اتجاه بصري بديل **لم يُعتمد**.
